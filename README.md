# Sistema de Gestão de Produtos (CRUD Web - MVC / DAO)

Aplicação Web desenvolvida com Node.js utilizando a arquitetura MVC (Model-View-Controller) e o padrão DAO (Data Access Object) para operações de CRUD em banco de dados relacional (MySQL).

## 🚀 Tecnologias Utilizadas
- **Node.js**
- **Express** (Servidor HTTP)
- **EJS** (View Engine / HTML Dinâmico)
- **MySQL2** (Conexão e operações no Banco)

## 📋 Pré-requisitos
- Node.js instalado na máquina.
- Servidor MySQL rodando.

## 🛠️ Como Executar o Projeto

1. **Configurar o Banco de Dados:**
   - Importe e execute o arquivo `script.sql` no seu gerenciador MySQL para criar a base e a tabela.
